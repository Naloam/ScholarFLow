# 论文质量改造计划（对标 FARS/ARIS，目标：中文核心可投）

## 前置结论（调研事实）

- **FARS**（Analemma，166 篇/$186k/417 小时）：每篇 $1120、1.3 亿 token，人类评审也只 17.7% 过 6/10——瓶颈在**实验充分性与论断忠实度，不是写作**。其可借鉴机制：论文蓝图（论断↔实验↔图表↔文献的证据链接）、逐节起草+编译/引用/数值核查循环、AI 完整性审计（8 类失败模式）。
- **ARIS**（开源）：跨模型对抗审稿（fresh 零上下文审稿人直读原始文件）、rubric 分维评分驱动修订收敛（实测单夜 5.0→7.5/10，4 轮封顶）、claims-evidence 矩阵、五遍科学编辑、三阶段证据审计。
- **我们稿子的实测缺口**（代码证据）：一次性写作+≤1次lint修订、审稿永不针对论文本身且设计上不可能通过、全文 0 图、表格缺强基线/消融列、相关工作=标题罗列（writer 根本拿不到 abstract）、文献 reported_results 有截断 bug 且下游无人消费、内部黑话（"锚定结论""kill 准则"）泄入正文。

## Phase A：论文生产管线重建（先做，零实验成本）

**A1 写作蓝图** `paper_blueprint.py` + `paper_blueprint_v1.md`
从 metrics/papers/假设生成蓝图 JSON：每个论断绑定{数字的 metrics 键路径, 图表占位, 相关文献+摘要要点, 所属章节}。落盘 `paper/blueprint.json`，是后续一切环节的唯一数据源（数字锚定不可变）。

**A2 逐节起草**（改造 writer.py + 新 section prompts）
按节生成（相关工作/方法/实验/讨论/结论/引言/摘要最后写），每节输入=蓝图切片+该节文献的 abstract/methods/reported_results+确定性生成的表格与图文件名。相关工作每段强制含具体方法+数字对比（lint 检查引用段落实质内容）。

**A3 表格与图表确定性生成** `tables_figures.py`（新依赖 matplotlib）
- 主表：全系统列（proposed/词法基线/强基线/消融 + Δ + 显著性），从 results 聚合生成，杜绝 LLM 手写错数
- 图 ≥2 张按假设类型路由：弃答→风险-覆盖曲线；校准→校准对比图；通用→主结果+跨数据集稳健性。中文字体，落 `artifacts/figures/`

**A4 审稿-修订收敛循环**（ARIS 式，新 `paper_reviewer_v1.md`）
分维 rubric（novelty/soundness/clarity/significance/相关工作深度，1-10 + major/minor actionable），审稿人 fresh 上下文、直读 draft+metrics 原文件。阈值：各维 ≥6 且无 major，最多 3 轮。分数轨迹落 ledger（可展示 5.0→6.5→7.2）。修订只动写作层，数字仍过确定性审计门。

**A5 终稿清洁与导出**（python-docx 回归依赖）
黑话确定性替换表 + `export.py`：manuscript → 投稿用 .docx（标题层级/表格/图嵌入/参考文献）。

**A6 中文期刊 prompt v2**：吸收以上全部。
